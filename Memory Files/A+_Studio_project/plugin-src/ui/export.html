How export works
Without GIF exports each selected A+ exactly as it is on the canvas: PNG or JPG for Amazon (also SVG or PDF). 1×, 2× and 3× multiply the frame's own size.

With GIF puts the A+ on top and its category's animation playing full-width underneath it, as one GIF or MP4. The animation comes from the team's Gifs folder in Google Drive: the file named after the category (Running → Running.mp4). The category is read from each frame; change it in the list if it is wrong. A frame whose category has no animation can still be exported as a still image.

Where it runs: everything is built on this computer: the frame images, the GIF/MP4, the ZIP. Files go straight from here to your download folder or to Google Drive.

Google Drive: paste a folder link. Each style ID gets its own subfolder inside it (706524/706524.gif); an A+ shared by several styles is saved in each of their folders.

Amazon: A+ image modules accept JPG or PNG only, max 2 MB. Animated GIFs are not accepted. An MP4 goes in a Premium A+ video module. Use the GIF for the website, social and decks.
