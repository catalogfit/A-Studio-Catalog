## Where things stand now

- **Working:** a Figma plugin, **A+ Studio v0.1**, with a **Run A+** button. It builds one Running A+ per sheet row: text, bold words, icons, photo placeholders, export slices and the style ID label.
- **Tested:** two A+ designs generated by the plugin's code sit on Page 2, to the right of RUNNING – Template 1:
  - 708587, 708589 (4 cards), Figma frame 631:2
  - 708133 (3 cards), Figma frame 631:67
- **Content sheet:** one tab, one row per A+. Column A holds the style IDs and columns B–G hold Cards 1–6 (`sheets/A+_Sheet_RUNNING_Template_1.xlsx`).
- **Not built yet:** Train, Lifestyle and Seamless buttons; exact cloning of your own template frame; Drive export and GIF; Google sign-in backend. See `what-i-want.md`.

## Timeline

### 1. The brief and the first PRD
**You asked for:** a PRD and a full execution plan for a Figma plugin that automates A+ designs. The details:
- Category templates (Running, Training, Plus/xtended, Seamless) made by the designers, with every frame, group, layer and vector kept intact.
- Content from a Google Sheet, mapped to style IDs.
- Colourways grouped under one grouping code.
- Images placed on placeholders, with manual Photoshop work where needed.
- GIFs added at export and files sent to Google Drive.
- Backend on Render first, Cloudflare later, with Google Auth.
- Zero cost and local processing; the plugin is shared by manifest.

You shared 3 A+ screenshots: xtended 707866 and its sibling, Training 70715x, and Running 706524.

**Delivered:** the Claude Doc "A+ Studio – PRD & Execution Plan" (https://claude.ai/artifact/1DCbQFLFyc8edc73V21Ps9). It covered:
- Screenshot analysis
- A layer-tagging "Template Contract"
- Sheet schema
- Architecture: a stateless backend that only handles Google sign-in
- 9-week roadmap from 2 Nov 2026
- Risks and open questions

**Noticed:**
- Run and Train use the same layout.
- The xtended size charts show faded leftover rows.
- 706524 mixes tee and shorts callouts.
- One Training callout shows a different garment.

### 2. Template refresh, placeholders, sheet structure
**You asked:** how to add, refresh, replace and delete templates (a Run redesign in six months), whether to feed templates in as SVG, a backend delete option, human images as placeholders, and a Google Sheet structure for the content person.

**Delivered:**
- **PRD update:** a new "Template lifecycle" section explaining why not SVG (it loses editable text and auto-layout) and how a template is a Figma component plus a registry row. It defines an Admin screen with Register, Test, Activate, Retire, Rollback and Delete.
- **Placeholders:** every human image became a placeholder throughout the PRD.
- **Sheet:** `A+_Content_Master_v1.xlsx`, 13 tabs.

**Outcome:** you said this was too complicated.

### 3. Rethink from the Figma file (first pass)
**You asked:** read the Figma file (Page 2), understand the A+ layout, and use a very simple one-row sheet: style IDs in column A, then content per card. You had labelled the cards COLUMN A–F next to RUNNING – Template 1.

**Found:** 19 A+ frames on Page 2. 17 of them (Running, Training, Lifestyle, Seamless) share one layout: hero, Fabric in Focus, then 3 or 4 callouts. Essentials is a different design.

**Delivered:** `A+_Content_Sheet_simple.xlsx`: one row per A+, 19 columns, 3 tabs, pre-filled with all 17 designs.

**Outcome:** you repeated the request, so this was still too complicated.

### 4. Rethink (second pass): the minimal sheet
**Noticed:** you had renamed the template frame to "706524" and removed the separate style ID label.

**Delivered:** `A+_Sheet_RUNNING_Template_1.xlsx`.
- **Layout:** one tab and 7 columns. A holds the style IDs; B–G hold Cards 1–6, one cell per card.
- **Inside a cell:** one line per text box, with bold marked as `**word**`.
- **Pre-filled** with the 6 existing 4-card Running designs.

### 5. Deep analysis of the Figma file
**You asked:** analyse the template, its layers and icons, and the other A+ designs. Explain how to "upload" a template so that choosing a category makes the design automatically.

**Delivered:** the analysis in `docs/figma-page2-analysis.md`.
- **Fonts:** Poppins, Racing Sans One and Fustat.
- **Icons:** some are PNG images, some are vectors.
- **Template problems:** the frame name, ungrouped cards, leftover stacked photos, a fixed-height fabric copy box, hand-placed titles, and stale layer names.
- **Proposal:** a template is just a frame named like "RUNNING – Template 1". The category comes from that name, so nothing is uploaded.

**Correction:** the Seamless tagline is "Seamless comfort in every move."; its layer name was stale.

### 6. Run A+ button built and tested
**You asked:** check the template and make a similar design inside the plugin (or as an SVG), so that choosing **Run A+** generates it from the content sheet.

**Delivered:** plugin **A+ Studio v0.1**.
- **Built from code:** it recreates RUNNING – Template 1 directly in code rather than through SVG, because SVG text can't be filled.
- **Reads the sheet** from a published CSV link or from pasted rows.
- **Builds one A+ per row:** text with bold, icons copied from A+ designs already on the page, dashed photo placeholders, export slices 1 and 2, the frame named by style ID, and the style ID label.
- **Tested** on Page 2 with two samples.
- **Fixes from testing:** vector icons such as "Stretchy" are now detected, and the fabric background placeholder label was moved to the corner.

### 7. Everything packed into this folder
Includes `history.md` (this file) and `what-i-want.md`.

## Decisions log

| # | Decision | Why |
|---|---|---|
| 1 | Templates stay as Figma designs, never SVG | SVG turns text into shapes and drops auto-layout, so nothing can be filled |
| 2 | Every human or model photo is a placeholder; text, icons and fabric visuals are automatic | Choosing the right model shot is the riskiest part to automate |
| 3 | One row = one A+ = one group of style IDs | Matches how Page 2 already works: one frame per group, style IDs stacked as a label |
| 4 | Sheet: column A style IDs, one cell per card, one line per text box, `**bold**` | You asked for the simplest possible sheet |
| 5 | Hero words are fixed per category; Card 1 is optional | All 17 existing designs repeat the same hero within their category |
| 6 | v0.1 builds the Run A+ from code inside the plugin | You asked for the design "inside" the plugin; it works in any file without setup |
| 7 | v0.1 reads the sheet by published CSV link or pasted rows | No backend or Google sign-in needed yet, so it costs nothing |
| 8 | Postponed, not dropped: layer-tag contract, 13-tab master workbook, Google OAuth backend, Drive export, GIF | Too much at once; they come back when the basics are in daily use |
